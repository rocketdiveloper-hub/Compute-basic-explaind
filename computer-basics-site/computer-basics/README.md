# Computer Basics Explained

A free, mobile-friendly beginner course on computer parts, Word, PowerPoint, and Excel.

**Live project:** [add your website link here]

## What is inside
- Learning paths, a searchable parts library (44 parts), a start-up simulator, Office lessons, a quiz, and a glossary
- Dark and light mode, responsive layout

## Run it
Open `index.html` in a browser. No build step or server needed.

## Add photos
Put photos in `images/` using the names in `images/README.txt`.

## Edit content
All parts, paths, lessons, quiz questions, and glossary terms are in `data.js`.
